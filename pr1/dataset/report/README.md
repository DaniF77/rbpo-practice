# Датасет github_ip_security_scan

Результаты ПР №1 (РБПО): диапазоны IP из GitHub Meta API и сканирование собственных ресурсов (Nmap, Masscan, Nikto).

- `data/scan_findings.csv` - все находки с экспертными комментариями
- `raw/` - исходный вывод инструментов и список диапазонов GitHub
- `meta/scan_findings.meta` - метаданные
- `report/expert_assessment.md` - экспертная оценка, `report/sources.md` - источники

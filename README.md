# rbpo-practice

Практические работы по дисциплине «Разработка безопасного программного обеспечения» (РБПО).

| Папка | Практическая работа |
|-------|---------------------|
| `pr1` | ПР №1: Git/GitHub, Meta API, анализ IP сканерами (Nmap, Masscan, Nikto), датасет с экспертной оценкой |
| `pr2` | ПР №2: SAST/DAST, CWE/CVE/OWASP, датасет уязвимостей |
| `pr3` | ПР №3: модели надёжности ПО (Джелински-Моранды, Шумана, Нельсона-Коркорэна) |
| `pr4` | ПР №4: информационно-аналитическая система безопасности |

Секреты, ключи и `.env` в репозиторий не попадают (см. `.gitignore`).
